# 自我学习生活多 Agent 个人助理

通过日常聊天记录待办，在新会话中结合用户记忆、资料与天气生成当天计划。

- 主 Agent：统一对话并组织计划。
- 执行 Agent：查询资料、地点和天气。
- 学习 Agent：从日常对话整理用户记忆，在后续任务中使用。

当前为规格与规划阶段，应用尚未实现。首版面向个人使用，外部 API 要求中国大陆无代理可用，真实联调待实现与账户配置就绪后进行。
