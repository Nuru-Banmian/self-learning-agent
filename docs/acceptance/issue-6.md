## 范围与设计

主 Agent 结合当前请求、真实待办、相关生效记忆提出 `research_learning`；执行 Agent 是只能搜索和读取资料的确定性执行器。搜索使用独立 IQS 凭据、固定官方 HTTPS 接口；不支持任意工具、外部写入或安装。主 Agent 的第二次调用只有返回步骤的工具，没有待办写入工具。引用 ID 必须对应实际资料；可选练习沿用现有建议、授权校验和防重复事务。

查询、输入摘要、实际请求、耗时、来源及四类结果通过 SSE 和 runs.research 持久保存。最多前 5 条资料、前 2 条正文，有限单次超时、整轮超时、共享调用和重试预算。正文读取失败保留摘要，摘要不标为正文。网页只进入最终组织上下文，不进入记忆提取。响应大小与展示长度有上限，禁止危险链接协议和内部 IP 地址。
