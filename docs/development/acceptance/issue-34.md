# Issue #34：简洁学习路线与按需详情

日期：2026-09-21。范围：[Issue #34](https://github.com/Nuru-Banmian/self-learning-agent/issues/34)，父规格 [#33](https://github.com/Nuru-Banmian/self-learning-agent/issues/33)。本项不修改 #35 的时间追问、排期或加入日期规则。

## 实现

- 首次生成、需求续答生成及调整概述使用简洁的有序节点回复。每节点保留短标题与具体目标，完整目标、练习、完成标准、来源和缺口仍在路线记录内。摘要同一次模型调用生成；后端校验并实际保存简洁正文，不靠 CSS 隐藏长消息，也不截断尾部节点。摘要正文预留最终记忆限制提示空间，总计不超过 800 个 Unicode 码点；无效/超预算模型结果不会保存为有效路线。
- 默认收起节点详情、来源、调整表单、排期表单和历史记录；现有排期能力仍保留，等待 #35 处理。保留顺序、进度和选择控件。对话仅在路线相关结果中折叠外部资料面板，普通研究/天气继续原行为。
- `GET /api/runs/{id}` 及会话助手消息补充 `roadmap_context`、`roadmap_links`。链接来自已保存请求/路线快照或已核对节点，包含真实 `roadmap_id`、可选 `node_id` 和标题；不解析回复字符串。增量数据库列保存只读详情请求的关联；旧消息原文不重写。
- 用户可在页面独立展开一个节点，或按路线标题/ID、节点标题/ID/序号询问详情。只读请求不调用模型或搜索、不生成方案或待办；多路线无法确定时澄清，支持带引号的明确路线名。
- 异常、超时和进程中断保留实际来源、调用及缺口，简短回复不再次附加搜索摘要。资料类型及正文截取标记继续忠实反映真实记录。学习页显示部分完成/失败及处理结果、重试入口。
- 内容调整保留未更改节点的简短字段及完成事实；修改路线标题时清除过期展示标题，页面显示新标题。
