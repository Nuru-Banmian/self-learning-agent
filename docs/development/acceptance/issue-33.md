## 本轮修复

- 每节点练习详情上限从 600 提高至 2400 Unicode 字符，路线生成、手动/模型调整共用后端模型；前端编辑器同步放宽。默认回复仍不超过 800 码点，全部节点顺序、折叠详情、来源和确认边界不变。
- 练习生成按准备、操作、验证组织，要求明确依赖与输入、完整脚本及运行命令，完成标准对应实际行为。提示词不能保证模型每次遵循，真实失败见下文。
- 真实调整响应恰好耗尽 1800 completion tokens 并出现截断 JSON。因此仅 `roadmap_answer` / `revision_answer` 的单次输出上限增至 8000 tokens，普通路由/记忆仍为 1800。调用次数、搜索预算、超时和存储授权不变。较长输出可能增加延迟与 token 费用，仍受原有超时保护。
- 公开 SSE 的 `model_result` 保存供应商 `finish_reason`；`length` 标为失败，不把被截断的路线当作有效结果，即使返回片段恰好能解析。不会自动执行生成的教学代码。
