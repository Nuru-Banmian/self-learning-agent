# 领域文档

本项目采用 single-context 布局：

- `CONTEXT.md`：位于项目根目录，记录领域概念和术语。
- `docs/adr/`：记录架构决策。

## 阅读规则

探索代码前，阅读已有的 `CONTEXT.md`，以及与当前工作相关的 ADR。
这些文件尚不存在时，直接继续工作，无需提示缺失或预先创建占位文档。
术语或决策明确后，由 `domain-modeling` 技能按需创建和维护。

## 术语与决策

Issue 标题、设计建议、假设和测试名称中的领域概念，沿用 `CONTEXT.md` 定义的术语。
需要的概念尚未定义时，先判断是否确有必要；确有缺口则记录给 `domain-modeling`。
方案与已有 ADR 冲突时，明确指出对应 ADR 和重新讨论的理由。
