# Triage labels

将技能中的分诊角色映射到本项目实际使用的标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交给 Agent 独立实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个分诊角色时，使用表中对应的 GitHub 标签。
以后调整标签名称时，修改本表的 GitHub 标签列。
